# ✨ Сайт портфолио

- Персональный сайт-портфолио на заказ, разработанный мной по готовому дизайну.
Моя задача заключалась в том, чтобы сверстать сайт, реализовать логику на React и обеспечить корректное отображение на разных устройствах.
- [Сайт можно посмотреть здесь](https://mayorlina.art/projects)

# 🚀 Основные возможности

- Главная страница со всеми проектами, в каждый можно перейти;
- Разделы: Обо мне, Проекты, Контакты;
- Карточки работ с кратким описанием;
- Форма обратной связи;
- Полностью адаптивная верстка под мобильные устройства;
- Легкая и понятная структура кода;

# 🛠 Использованные технологии

- React - компоненты и SPA-архитектура
- Vite - современная сборка с HMR
- React Router - переходы между разделами
- SCSS - модульные стили и адаптив
- JavaScript (ES6+)
- ESLint + Prettier - для единообразия кода

# 📁 Структура проекта
```
portfolio-website/
├── public/                # статические файлы
├── src/
│   ├── assets/            # изображения и иконки
│   ├── components/        # UI-компоненты (Header, Footer, ProjectCard и др.)
│   ├── pages/             # страницы (Home, About, Projects, Contact)
│   ├── styles/            # SCSS-модули
│   ├── App.jsx            # основной компонент
│   └── main.jsx           # точка входа
├── index.html             # HTML-шаблон
├── vite.config.js         # конфигурация Vite
└── package.json
```
# ✅ Установка и запуск

```
git clone https://github.com/sadtakesh1/portfolio-website.git
cd portfolio-website
npm install
npm run dev
```
